# quinone_co2cap_dataset
Dataset of computed values for PubChem quinones, aimed to calculate theoretical values of 2nd reduction potential and CO2 capture constant.

In the AllQs Gibbs dataset:
anion and dianion energies are in Hartrees
reduction potentials (dE_eV) are reported in eV
starting material (SM) energies include Gibbs energy for CO2 + dianion
all energies are reported for implicitly solvated species in DMF
